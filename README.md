# Ночная оборона (Last Row)

Вертикальный tower defense для Telegram Mini App. Заброшенная ферма ночью,
враги идут сверху вниз, игрок держит последний рубеж.

Чистый HTML5 + CSS + JavaScript. Без сборщиков, без зависимостей, без внешних
картинок: вся графика рисуется кодом на `<canvas>`, интерфейс вокруг поля — DOM.

## Запуск

Открыть `index.html` в браузере — этого достаточно, скрипты подключены обычными
тегами `<script>`, сборка не нужна.

Для Telegram Mini App: положить файлы на любой статический хостинг с HTTPS
и указать URL в настройках бота через BotFather. Вне Telegram игра работает
так же — все обращения к SDK обёрнуты в проверки.

## Структура

```
index.html           разметка экранов и оверлеев
css/style.css        палитра, компоновка, анимации интерфейса
js/main.js           точка входа, навигация, поворот экрана, пауза в фоне
js/game.js           CONFIG баланса, игровой цикл, бой, отрисовка поля
js/grid.js           палитра для канваса и логика сетки 5x7
js/units.js          защитники: параметры, апгрейды, отрисовка
js/enemies.js        враги: параметры, особенности, отрисовка
js/waves.js          LEVELS — все 10 уровней и волны данными
js/ui.js             экраны, карточки, модалки, обучение
js/storage.js        прогресс в localStorage
js/telegram.js       Telegram Web App SDK
js/sound.js          синтезированные звуки через Web Audio
```

## Баланс

Все числа собраны в четырёх местах и меняются без правки логики:

- `CONFIG` в начале `js/game.js` — жизни, паузы между волнами, скорости снарядов
- `UNIT_TYPES` в `js/units.js` — стоимость, урон, скорострельность, дальность
- `ENEMY_TYPES` в `js/enemies.js` — HP, скорость, урон, особенности
- `LEVELS` в `js/waves.js` — 10 уровней по 10 волн, каждая волна описана данными

## Содержание

- 10 уровней кампании, уровень открывается после прохождения предыдущего
- 6 защитников: маяк, стрелок, барьер, морозильник, дробовик, мина
- 5 типов врагов плюс босс-колосс на 5-м и 10-м уровнях
- улучшение юнита за двойную цену, продажа с возвратом половины
- режим «бесконечные волны» после прохождения кампании
- звук, тактильная отдача, шаринг результата, сохранение прогресса
